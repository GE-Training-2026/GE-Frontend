## GEHYD – Modern Web Layouts (HTML & CSS)

- This project is a frontend layout showcase built using pure HTML and CSS.
- It demonstrates commonly used modern web layouts that are essential for building real-world websites and web applications.

- The goal of this project is to practice layout design concepts such as navigation bars, hero sections, grids, cards, galleries, and media objects.

## Features

- Responsive navigation bar

- Intro (Hero) section

- Sample website layout using CSS Grid

- Responsive photo gallery

- Card-based content layout

- Media object layout (used in comments, reviews, profiles)

- Clean and semantic HTML structure

- External CSS styling

## Tech Stack

| Technology | Usage                    |
| ---------- | ------------------------ |
| HTML5      | Page structure & content |
| CSS3       | Styling & layouts        |
| Unsplash   | Demo images              |
| Pravatar   | User avatar images       |
